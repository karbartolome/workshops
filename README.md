## Repo structure

Every workshop lives in its own folder under [slides/](slides/), e.g.
[slides/20240513-uba-calibracion/](slides/20240513-uba-calibracion/). A folder is
picked up as a workshop as long as it contains a rendered `slides*.html` deck
(the source `.qmd`, notebooks, images, etc. can live alongside it).

The landing page (this site's homepage) is built by three files that work
together:

- **[main.py](main.py)** — the generator script. Run it with `python main.py`
  whenever a new workshop is added or a description/tag changes. It:
  1. Scans `slides/` for folders containing a rendered slide deck.
  2. Adds a skeleton entry to [metadata/slides_descriptions.json](metadata/slides_descriptions.json)
     for any newly discovered deck (title/date/description/tags are left empty
     for you to fill in).
  3. Regenerates [index.qmd](index.qmd) with a filterable card grid, one card
     per deck, sorted by date.
  4. Renders `index.qmd` into `index.html` with the Quarto CLI (skip this step
     with `python main.py --no-render`).
  5. Rewrites [404.html](404.html) so links to workshops' old, pre-migration
     URLs (e.g. `.../20240513-uba-calibracion/slides`, from before decks were
     moved into `slides/`) still redirect to their new location under
     `slides/`. GitHub Pages serves this file whenever a requested path
     doesn't exist, so the redirect happens client-side.
- **[index.qmd](index.qmd)** — the generated Quarto source for the homepage.
  It's overwritten by `main.py` on every run, so edit it only to tweak the
  generator's templates (in `main.py`), not this file directly.
- **[index.html](index.html)** — the rendered homepage, produced by Quarto
  from `index.qmd`. This is the file GitHub Pages actually serves at
  `/`. It's also regenerated by `main.py`, don't edit it by hand.

## Configs

Para configurar kernelspec: 

conda create -n quarto-env python=3.10
conda activate quarto-env
conda install notebook ipykernel
ipython kernel install --user --name quarto-env --display-name quarto-env
conda install numpy
etc.

```
jupyter: 
  kernelspec:
    name: "quarto-env"
    language: "python"
    display_name: "quarto-env"
```
